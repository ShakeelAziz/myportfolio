# Shakeel Ahmad Portfolio

A responsive personal portfolio built with HTML5, Tailwind CSS (CDN), and vanilla JavaScript.

## Included Content

- Professional summary and experience
- Skill areas: Software Development, Mobile Development, AI Automations, WordPress, Wix, Google Ads, Flutter, Kotlin
- Featured projects from public LinkedIn profile data
- Education and languages
- Contact and LinkedIn call-to-actions

## Files

- `index.html` - main layout and sections
- `script.js` - data model and UI rendering logic
- `styles.css` - small global style enhancements
- `assets/profile-hero.svg` - hero image asset
- `assets/projects-banner.svg` - projects section image asset

## Run Locally

Open `index.html` directly in your browser.

## Notes

- Tailwind is loaded through CDN for quick setup.
- Profile content is based on public details from: <https://www.linkedin.com/in/shakeelaziz8>
